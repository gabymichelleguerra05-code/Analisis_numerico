1 Introducción

El presente proyecto analiza el artículo Deterministic Nonperiodic Flow de Edward N. Lorenz, publicado en 1963. En este trabajo, Lorenz muestra que un sistema determinista puede presentar trayectorias no periódicas, es decir, comportamientos que no se repiten exactamente y que son díficiles de predecir a largo plazo. Desde una perspectiva económica, esta idea permite reflexionar sobre cómo ciertas variables, como la producción, la demanda y la inflación, pueden interactuar de manera no lineal. A pesar de que el sistema siga reglas definidas, pequeñas variaciones en las condiciones iniciales pueden generar resultados muy distintos.

2 Enfoque del proyecto

Este proyecto no busca aplicar el modelo de Lorenz de manera literal a una economía real, sino reinterpretarlo como una herramienta numérica para visualizar la complejidad de los sistemas económicos. Nuestra propuesta consiste en relacionar las variables del modelo con producción, demanda e inflación, con el objetivo de mostrar cómo pequeñas variaciones iniciales pueden modificar la trayectoria de un sistema dinámico.

3 Pregunta guía

Para poder darle una interpretación a este modelo, vamos a partir de la siguiente pregunta: ¿Cómo puede el modelo de Lorenz ayudar a explicar la inestabilidad y dificultad de predicción en sistemas económicos?

4 Hipótesis

7 Explicación del artículo de Lorenz

Edward Lorenz desarrolló un modelo matemático originalmente relacionado con fenómenos atmosféricos y climáticos. En su artículo Deterministic Nonperiodic Flow (1963), demostró que ciertos sistemas dinámicos pueden comportarse de manera impredecible, aun cuando estén gobernados por ecuaciones deterministas. Lorenz observó que pequeñas diferencias en las condiciones iniciales producían trayectorias completamente distintas con el paso del tiempo. A este fenómeno posteriormente se le relacionó con el llamado “efecto mariposa”, donde pequeñas variaciones pueden generar grandes cambios en el comportamiento del sistema. Todo esto le permitió al modelo convertirse en uno de los principales antecedentes de la teoría del caos, demostrando que no todos los sistemas siguen patrones estables o periódicos.

Así que desde una perspectiva económica, este comportamiento puede relacionarse con variables como la inflación, la producción o las expectativas de mercado. Aunque la economía siga ciertas reglas y modelos matemáticos, pequeñas variaciones pueden provocar cambios importantes en el comportamiento económico a largo plazo.

8 Sistema de ecuaciones de Lorenz

El modelo de Lorenz está definido por el siguiente sistema de ecuaciones diferenciales:

\[ \begin{aligned} \frac{dx}{dt} &= \sigma (y-x) \\ \\ \frac{dy}{dt} &= x(\rho-z)-y \\ \\ \frac{dz}{dt} &= xy-\beta z \end{aligned} \]

Estas ecuaciones describen la interacción no lineal entre las variables del modelo y permiten analizar el comportamiento caótico del sistema.

from scipy.integrate import odeint 
import numpy as np
import matplotlib.pyplot as plt
# Parámetros del modelo 
sigma = 10
rho = 28
beta = 8/3

# Sistema de ecuaciones
def lorenz(state, t):
    x, y, z = state

    dx= sigma * (y - x)
    dy= x * (rho - z) - y
    dz= x * y - beta * z

    return [dx,dy,dz]

9 Simulación numérica del modelo

Para resolver el sistema se utiliza integración numérica. En este caso se emplea odeint, que permite aproximar la solución de un sistema de ecuaciones diferenciales a partir de condiciones lineales.

# Condiciones lineales
estado_inicial = [1, 1, 1]

# Intervalo de tiempo 
t = np.linspace(0, 40, 10000)

# Solución numérica del sistema 
solucion = odeint(lorenz, estado_inicial, t)

# Separar las variables
x = solucion[:, 0]
y = solucion[:, 1]
z = solucion[:, 2]

Para esta simulación, las variables las interpretaremos de la siguiente manera: - x: producción o actividad económica. - y: demanda o expectativas económicas. - z: inflación o presión de precios.

La condición incial será [1, 1, 1], que representa un punto de partida del sistema económico. A partir de ese punto, el modelo muestra cómo evolucionan las variables en el tiempo.

15 Interpretación económica del modelo

El modelo de Lorenz permite comprender que algunos sistemas económicos pueden comportarse de forma compleja aunque estén determinados por relaciones matemáticas específicas. En este proyecto, las variables del modelo se reinterpretaron como producción, demanda e inflación. La producción puede modificarse según el comportamiento de la demanda; la demanda puede verse afectada por las expectativas de los agentes económicos; y la inflación puede responder a presiones acumuladas dentro del sistema. La principal aportación del modelo es mostrar que pequeñas variaciones iniciales pueden generar resultados muy diferentes. Esto ayuda a explicar por qué en economía no siempre es posible realizar predicciones exactas a largo plazo, especialmente cuando existen interacciones no lineales entre las variables. Por lo tanto, el modelo de Lorenz no predice directamente una economía real, pero sí funciona como una herramienta teórica y numérica para visualizar la inestabilidad, la sensibilidad y la complejidad de los sistemas económicos.

16 Conclusión

A partir del artículo de Lorenz y de la simulación numérica realizada, se puede concluir que los sistemas deterministas no siempre presentan comportamientos simples o predecibles. Aunque el modelo está formado por ecuaciones definidas, sus soluciones pueden evolucionar de forma irregular y sensible a las condiciones iniciales.

Al reinterpretar el modelo desde una perspectiva económica, fue posible relacionar sus variables con la producción, la demanda y la inflación. Esta adaptación permite observar cómo pequeñas variaciones en el punto de partida pueden generar trayectorias económicas distintas, lo cual ayuda a comprender la dificultad de predecir ciertos fenómenos económicos a largo plazo.

El uso de Python fue de gran ayuda para resolver numéricamente el sistema de ecuaciones y representar los resultados de una forma gráfica. De este modo, el análisis numérico se convirtió en una herramienta útil para estudiar modelos dinámicos y visualizar comportamientos complejos.

Finalmente, el modelo de Lorenz muestra que la economía, al igual que otros sistemas dinámicos, puede presentar inestabilidad y sensibilidad. Por ello, más que ofrecer predicciones exactas, este tipo de modelos permite comprender mejor la complejidad de los fenómenos económicos.

Podemos observar que las trayectorias evolucionan de forma completamente distinta con el tiempo, demostrando la sensibilidad a las condiciones iniciales característica de los sistemas caóticos, fenómeno conocido como efecto mariposa.

# Interpretación económica del modelo

El modelo de Lorenz permite comprender que algunos sistemas económicos pueden comportarse de forma compleja aunque estén determinados por relaciones matemáticas específicas. En este proyecto, las variables del modelo se reinterpretaron como producción, demanda e inflación. La producción puede modificarse según el comportamiento de la demanda; la demanda puede verse afectada por las expectativas de los agentes económicos; y la inflación puede responder a presiones acumuladas dentro del sistema. La principal aportación del modelo es mostrar que pequeñas variaciones iniciales pueden generar resultados muy diferentes. Esto ayuda a explicar por qué en economía no siempre es posible realizar predicciones exactas a largo plazo, especialmente cuando existen interacciones no lineales entre las variables. Por lo tanto, el modelo de Lorenz no predice directamente una economía real, pero sí funciona como una herramienta teórica y numérica para visualizar la inestabilidad, la sensibilidad y la complejidad de los sistemas económicos.

# Conclusión 
A partir del artículo de Lorenz y de la simulación numérica realizada, se puede concluir que los sistemas deterministas no siempre presentan comportamientos simples o predecibles. Aunque el modelo está formado por ecuaciones definidas, sus soluciones pueden evolucionar de forma irregular y sensible a las condiciones iniciales.

Al reinterpretar el modelo desde una perspectiva económica, fue posible relacionar sus variables con la producción, la demanda y la inflación. Esta adaptación permite observar cómo pequeñas variaciones en el punto de partida pueden generar trayectorias económicas distintas, lo cual ayuda a comprender la dificultad de predecir ciertos fenómenos económicos a largo plazo.

El uso de Python fue de gran ayuda para resolver numéricamente el sistema de ecuaciones y representar los resultados de una forma gráfica. De este modo, el análisis numérico se convirtió en una herramienta útil para estudiar modelos dinámicos y visualizar comportamientos complejos.

Finalmente, el modelo de Lorenz muestra que la economía, al igual que otros sistemas dinámicos, puede presentar inestabilidad y sensibilidad. Por ello, más que ofrecer predicciones exactas, este tipo de modelos permite comprender mejor la complejidad de los fenómenos económicos.
